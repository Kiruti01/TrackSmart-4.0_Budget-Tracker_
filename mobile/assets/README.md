# Assets Directory

This directory should contain the app's image assets.

## Required Files

You need to create the following image files:

1. **icon.png** (1024x1024)
   - App icon displayed on home screen
   - Should be a simple, recognizable design

2. **splash.png** (1242x2436)
   - Splash screen shown when app launches
   - Can include app logo and name

3. **adaptive-icon.png** (1024x1024, Android)
   - Android adaptive icon
   - Center content should be within safe zone

4. **favicon.png** (48x48)
   - Web favicon (if using Expo web)

## Creating Assets

You can:
1. Design your own using tools like Figma, Adobe XD, or Canva
2. Use placeholder images for testing
3. Generate icons using: https://www.appicon.co/

## Quick Placeholder Setup

For testing, you can create simple colored squares:
- Use any image editor to create 1024x1024 colored squares
- Name them according to the list above
- Place them in this directory

The app will work with placeholder assets during development.
